# Legacy Tk client

Reference only. Not shipped. Removed from the apworld in v1.1.

`client.py` is the v1.0.2 Taskipelago Tk client, moved here verbatim so its line
numbers stay valid as the behavior reference for the JS port in
`custom_worlds/taskipelago/web-client/`.

It imports `.prereq_parser` and Archipelago's `CommonClient`, so it will not run
from this directory. That is expected.
