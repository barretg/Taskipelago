# Taskipelago/Taskipelabingo Version 1.1.1
*One client to rule them all and also I fixed the bug with item count syntax*

Quick bug fix patch because * syntax wasn't supported for duplicate items.

## What's new (v1.1.0)
* One unified web client that hosts itself from the apworld, or is hosted at the [usual web address](https://barretg.github.io/Taskipelago/web-client/).
* Hints tab
* Deathlink alerts with noises that can be turned on and off
* Deathlink lock mode
* Deathlink task rows
* Item filtering on items tab
* Find/replace on YAML Generator
* Renaming something optionally updates all references for your convenience
* Reordering of tasks/items is now supported
* Progressive groups now have colors tied to them
* Bingo now generates filler if no items are listed
* Fixed case where names with trailing special characters made things a little funky

Note: should be fully backwards compatible with worlds generated at v1.0.2. Also Universal Tracker is still incompatible.
